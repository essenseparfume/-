МІЙ ПАРФУМЕРНИЙ СКЛАД — версія для встановлення на iPhone

У ZIP є файли вебдодатка (PWA). Щоб встановити його як іконку на iPhone:
1. Спочатку розмісти всі файли цієї папки на HTTPS-хостингу (наприклад, GitHub Pages).
2. Відкрий адресу сайту в Safari на iPhone.
3. Натисни «Поділитися» → «На початковий екран» (Add to Home Screen).
4. Якщо показується опція «Відкрити як вебдодаток», увімкни її та натисни «Додати».

Важливо:
- ZIP напряму не встановлюється як iPhone-додаток; для встановлення потрібна HTTPS-адреса.
- Це вебдодаток, не застосунок з App Store.
- Кількість, додані аромати й фото зберігаються локально в Safari на цьому iPhone.
- Резервні копії роби кнопкою «Експорт копії» всередині сайту.
- Сам каталог не має входу/пароля; якщо сайт розміщений за посиланням, інші можуть відкрити сторінку, але їхній локальний список окремий від твого.
